# OneSync Website – Inspiration & Structure

## 1. Reference Products (Design Inspiration)

The OneSync website draws inspiration from high-end wearable and performance platforms such as WHOOP and Ultrahuman. These sites succeed because they:

- Communicate value immediately
- Use strong visual hierarchy
- Break complexity into scrollable sections
- Balance aspiration with technical credibility

OneSync will adopt these patterns while clearly differentiating itself through trust, privacy, and system-level intelligence.

---

## 2. Core Website Objective

The website must:
- Feel premium and modern
- Be engaging and scroll-friendly
- Explain a complex system without overwhelming
- Demonstrate the product "in action" through UI simulation

This is not an e-commerce site. It is a **product understanding and trust-building surface**.

---

## 3. Homepage Structure (WHOOP / Ultrahuman Style)

### 3.1 Hero Section

Purpose: Immediate clarity and emotional hook

- Headline: One clear value statement
- Subheadline: What makes OneSync different (edge-first, privacy-first)
- Visual: System illustration or product render
- CTAs:
  - View Live Demo
  - See How It Works

---

### 3.2 Vision / Problem Section

Purpose: Frame the problem OneSync solves

- Short statement about broken wearable intelligence
- Comparison: Traditional wearables vs OneSync approach
- Visual: Split or layered comparison graphic

---

### 3.3 Core Benefits (Modular Cards)

Inspired by WHOOP / Ultrahuman benefit blocks

Cards:
- Trust by Design
- Conditional Intelligence
- Edge-First Computation
- Athlete-Controlled Data

Each card includes:
- Icon
- Title
- One-paragraph explanation

---

### 3.4 Product in Action (Key Engagement Section)

Purpose: Show, not tell

- Simulated dashboard
- Insight cards with confidence
- NO INFERENCE states
- Mode switching (Sleep / ADL / Training)

This section is interactive or subtly animated.

---

### 3.5 How It Works

Purpose: Reduce complexity

Steps:
1. OneBand senses and computes
2. OneSync Mobile enforces consent
3. Cloud aggregates features only
4. Insights shown with confidence

Visual: Horizontal or vertical flow diagram

---

### 3.6 Trust, Privacy, and Governance

Purpose: Differentiation

- What is collected
- What is never collected
- Who controls the data
- Why this matters

Use icons and simple language.

---

### 3.7 Validation / Credibility Section

Inspired by testimonials and endorsements

- Research-aligned claims
- Target user quotes (placeholder initially)
- Elite performance positioning

---

### 3.8 Footer

- Product
- Demo
- System Architecture
- Privacy
- Contact

---

## 4. Secondary Pages

- /demo – Interactive product simulation
- /system – Architecture and data flow
- /privacy – Clear, visual governance
- /technology – Edge, ML, and security overview

---

## 5. UX Principles (Borrowed and Adapted)

- Large sections, slow scroll
- Visual first, text second
- Progressive disclosure
- No clutter, no noise

---

## 6. What Makes OneSync Visually Different

Unlike WHOOP or Ultrahuman:
- Confidence and uncertainty are visible
- NO INFERENCE is normalized
- System boundaries are explicit

This must be reflected in UI design.
