## 5. 3D Product Renders

### Option A: AI 3D Generation

**Tool: [Meshy.ai](https://www.meshy.ai/)** (Free tier)

```
PROMPT:
"Minimalist black fitness wristband, smooth matte finish,
small rectangular display, simple clasp, wearable tech"
```

- Generates 3D model from text
- Export as GLB for Three.js
- Can generate multiple angles

**Tool: [Kaedim](https://www.kaedim3d.com/)** (Paid)

- Upload 2D image → Get 3D model
- Good for product visualization

**Tool: [CSM.ai](https://csm.ai/)** (Free tier)

- Image to 3D model
- Good quality output

### Option B: Pre-made 3D Assets

**[Sketchfab](https://sketchfab.com/search?q=smartwatch&type=models)**
- Search "smartwatch" or "fitness band"
- Many free models available
- Download as GLB

**[Turbosquid](https://www.turbosquid.com/Search/3D-Models/free/smartwatch)**
- Professional 3D models
- Some free options

### Option C: Blender Quick Render (If you have Blender)

**Basic band model steps:**
1. Create cylinder, flatten it
2. Boolean cut for display area
3. Add subdivision surface
4. Apply dark material with slight roughness
5. Set up 3-point lighting (one gold-tinted)
6. Render 120 frames rotating 360°

### Generating Frame Sequence

If using AI-generated images, you can fake the rotation:

**Midjourney Prompt Series:**
```
Frame 1 (Front): "Black fitness band, front view, product shot, dark background --ar 1:1"
Frame 2 (3/4): "Black fitness band, three quarter view, product shot, dark background --ar 1:1"
Frame 3 (Side): "Black fitness band, side profile view, product shot, dark background --ar 1:1"
Frame 4 (Back 3/4): "Black fitness band, back three quarter view, product shot, dark background --ar 1:1"
Frame 5 (Back): "Black fitness band, back view, product shot, dark background --ar 1:1"
```

Generate 5-10 key angles, then use video interpolation tools:
- [Runway Frame Interpolation](https://runwayml.com/)
- [Film](https://github.com/google-research/frame-interpolation) (free, local)
