## Tips for Best Results

### Gemini/Nano Banana
- Always upload reference image first
- Use "exact reference" language
- Specify quality (8K, photorealistic)
- Be explicit about texture (woven braided mesh)

### ChatGPT/DALL-E 3
- Use Gen ID method for consistency
- Stay in same conversation session
- Include full product DNA in first prompt
- Request Gen ID after each generation

### Veo 2 Video
- Upload clearest reference image
- Specify "slow rotation" to avoid texture smearing
- Request "soft top light + rim light"
- Keep background simple (dark gradient)
